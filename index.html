Risk Score API

Wallet and transaction risk lookups backed by the Alpha AML upstream API. Returns a styled PDF report for an address, or JSON risk metadata for the two parties of a transaction.

Base URL

https://api.alpha-aml.com

GET /api/report/wallet

Returns a PDF AML risk report for the given wallet address and chain.

GET /api/report/wallet?address={address}&chain={chain}

Headers

HeaderDescription
X-apikeyrequired Caller JWT. Per-key rate limits apply (10/s, 100/min, 2000/day). Not a query parameter — sending it as ?apiKey= no longer works.

Query Parameters

ParameterTypeDescription
addressrequired string Wallet address to check. Blank or missing → 400.
chainoptional string Blockchain the address belongs to. If omitted, upstream API attempts auto-detection. When supplied, an address whose family does not match the chain is rejected with UNSUPPORTED_CHAIN.

Supported chain values:

ETH ARB BASE BSC TRON

Response

StatusContent-TypeBody
200application/pdfGenerated PDF bytes. Header: Content-Disposition: attachment; filename="aml-report-<address>.pdf".
400application/jsonINVALID_ADDRESS (bad format), UNSUPPORTED_CHAIN (address family ≠ chain), BAD_REQUEST (missing param).
401application/jsonMissing or invalid X-apikey — rejected before this endpoint runs.
403application/jsonKey has no access to this endpoint.
404application/jsonADDRESS_NOT_FOUND — no upstream data for the address.
429application/jsonRate limit exceeded — Retry-After header and retry_after_seconds in the body say when to retry.
500application/jsonPDF_FAILED — Chromium failed to render the report.
App-level errors (400/404/500) are JSON — { "error": { "code", "field", "message" } }. Auth/rate-limit errors (401/403/429) come from the SDK layer before the request reaches this endpoint. Every response — success or error — carries an X-Request-Id header for tracing. A successful call still returns the raw PDF. See the Error Reference for app-level codes.

curl Examples

curl -H "X-apikey: <key>" \
  "https://api.alpha-aml.com/api/report/wallet?address=0x7f367cc41522ce07553e823bf3be79a889debe1b&chain=ETH" \
  -o aml-report.pdf
COPY 
curl -H "X-apikey: <key>" \
  "https://api.alpha-aml.com/api/report/wallet?address=TXyz1234567890abcdefgh&chain=TRON" \
  -o aml-report.pdf
COPY

GET /api/report/txhash

Resolves a transaction hash to a single transfer, then returns JSON risk metadata for both parties of that transfer. This endpoint does not generate a PDF — use /api/report/wallet with the returned sender / receiver for the styled report.

GET /api/report/txhash?txHash={txHash}&chain={chain}

Headers

HeaderDescription
X-apikeyrequired Caller JWT. Per-key rate limits apply (10/s, 100/min, 2000/day). Not a query parameter — sending it as ?apiKey= no longer works.

Query Parameters

ParameterTypeDescription
txHashrequiredstringTransaction hash. EVM chains: 0x + 64 hex. TRON: 64 hex, no 0x. Wrong shape for the chain → INVALID_TX_HASH.
chainrequiredstringChain to resolve the transaction on. One of the supported values below.
event_indexoptionalintegerFilter: keep only the token transfer whose log index equals this value (the number shown under a transaction's event logs on a block explorer). Native transfers have no log index.
token_contractoptionalstringFilter: keep only token transfers of this contract address.
senderoptionalstringFilter / assertion: keep only transfers sent from this address.
recipientoptionalstringFilter / assertion: keep only transfers received by this address.

Supported chain values:

ETH ARB BASE BSC TRON

Transfer Selection

Exactly one transfer is scored. The optional parameters filter the transaction's transfers — the native value transfer (if any) plus every ERC-20 / TRC-20 Transfer log event.

SituationResult
No filters — exactly one native transfer, no token transfersThat native transfer is used.
No filters — no native transfer, exactly one token transferThat token transfer is used.
No filters — a native transfer and token transfers, or more than one token transfer409 MULTIPLE_TRANSFERS — add a filter.
No filters — no transfers at all409 NO_TRANSFERS.
Filters given — no transfer matches409 NO_MATCH.
Filters given — more than one transfer still matches409 MULTIPLE_TRANSFERS — narrow further.
Filters given — exactly one matchThat transfer is used.

Response

StatusContent-TypeBody
200application/jsonTransfer metadata + risk scores (fields below).
400application/jsonINVALID_TX_HASH, UNSUPPORTED_CHAIN, INVALID_ADDRESS, BAD_REQUEST.
401application/jsonMissing or invalid X-apikey — rejected before this endpoint runs.
403application/jsonKey has no access to this endpoint.
404application/jsonUNKNOWN_HASH, ADDRESS_NOT_FOUND.
409application/jsonPENDING_TRANSACTION, TRANSACTION_FAILED, NO_TRANSFERS, MULTIPLE_TRANSFERS, NO_MATCH.
429application/jsonRate limit exceeded — Retry-After header and retry_after_seconds in the body say when to retry.
502application/jsonRPC_ERROR — RPC provider unreachable or returned an error.

Response Fields (200 OK JSON)

application/json — transfer metadata + risk scores
versionstringResponse schema version (e.g. "1.2.15"). Constant until this endpoint's response shape changes.
hashstringThe transaction hash (echo of txHash).
chainstringChain the lookup ran on (echo of chain).
amountstringTransferred amount, decimal-adjusted, trailing zeros stripped (e.g. "490.14").
amount_rawstringTransferred amount in base units (wei / sun / token base units).
assetstring"native" for a coin transfer, otherwise the token contract address.
decimalsnumberDecimals used for amount — 18 (native EVM), 6 (native TRON), or the token's own.
token_symbolstringToken symbol if it could be read on-chain; omitted for native transfers or when unavailable.
senderstringThe selected transfer's from address.
funding_entity_typesarraySender only. The sender's funded_by_entity_type_distribution from the Alpha AML API — [{ label, percentage }]. Omitted if the sender has no funding data.
receiverstringThe selected transfer's to address.
sender_risk_scorenumber0–100 risk score for sender. null if it could not be scored.
receiver_risk_scorenumber0–100 risk score for receiver. null if it could not be scored.

GET /api/engine/report-v1

Returns a full risk assessment for a single address: score, the findings behind it, attribution for the address and its counterparties, and metadata describing how complete and how current the analysis is.

GET https://api.alpha-aml.com/api/engine/report-v1?address={address}&chain={chain}
Read report.status before risk_assessment.score. A score is only an assessment when status is complete; otherwise it is preliminary or absent. score is null whenever status is not complete.

Headers

HeaderDescription
X-apikeyrequired API key. Header only — a key supplied as ?apiKey= returns 401.
User-Agentoptional Send an identifying value such as your-app/1.0. Some default library agents are filtered at the edge.

Query Parameters

ParameterTypeDescription
addressrequired string Address to score. Validated for the requested network before any scoring runs; a malformed address is rejected rather than scored.
chainoptional string Accepts ethereum / ETH / eth and tron / TRON. Defaults to ethereum when omitted. Never substituted when supplied: a Tron address sent with chain=ethereum returns INVALID_ADDRESS.
blockoptional integer Point-in-time evaluation. Scores the address using only events at or before this block, and echoes it back as report.as_of_block. Omit for current state.

Supported Networks

ethereum tron

curl Example

curl -H "X-apikey: <key>" -A "your-app/1.0" \
  "https://api.alpha-aml.com/api/engine/report-v1?address=0x08723392ed15743cc38513c4925f5e6be5c17243&chain=ethereum"
COPY

Response Fields

report — identity, completeness and data freshness
report_idstringIdentifies this result: rpt_ + 32 hex. Deterministic — identical inputs return an identical id, and it changes whenever anything affecting the answer changes (new data, new model version, different block). Re-reading a finished report is therefore distinguishable from a fresh recalculation. Not a random UUID.
statusstringcomplete — analysis ran in full. partial — a component was unavailable; the score is preliminary. unavailable — no analysis was performed. Branch on this before reading score.
reasonstringPresent only when status != complete. Current values: CACHE_WARMING, COUNTERPARTY_LOOKUP_FAILED, ENTITY_GEO_LOOKUP_FAILED, RELATED_ENTITIES_LOOKUP_FAILED, AGGREGATES_NOT_BUILT. Treat unknown values as partial.
coveragestringfull — the address has history and it was analysed. no_history — a valid address with zero transfers; distinct from "could not analyse". partial_history — history exists but was not fully covered.
is_finalbooleanTrue only when status = complete. A final report is reproducible: identical inputs return a byte-identical payload.
preliminarybooleanInverse of is_final. A preliminary score is never presented as final.
model_versionstringIdentifies the scoring model and its configuration, e.g. 4.1.0-da50fad0. Two reports carrying the same value were produced by the same model against the same configuration. Changes when either changes.
generated_at_utcstringISO-8601 UTC timestamp of this response.
as_of_blockintegerEcho of the block parameter. Present only when a point-in-time query was requested.
data_as_of.chain_head_blockintegerHighest block indexed for this network.
data_as_of.graph_blockintegerBlock up to which the exposure graph is computed.
data_as_of.graph_lag_blocksintegerDifference between the two. Wallet activity is current to the chain head; graph exposure is current to graph_block. Index lag is therefore visible and never looks like an absent wallet history.
wallet — subject of the report
addressstringEchoes the requested address, in the network's native format. Base58 case is preserved for Tron.
blockchainstringUppercase network name, e.g. ETHEREUM, TRON.
descriptionstringKnown label for the address, where one is held. Empty otherwise.
entity_tagstringSet to Smart contract when the address is a contract. Useful for blocking plain transfers to token contracts, which are unrecoverable.
risk_assessment — the headline verdict
scorenumber | nullRisk score, 0–score_max. May be null when status != complete. Never read a missing or zero score as clean.
score_maxintegerScale maximum, currently 100. Always positive.
risk_levelstringVERY LOW RISK / LOW RISK / HIGH RISK / VERY HIGH RISK. Note there is no MEDIUM string: scores 41–50 return LOW RISK. Threshold on score, not on this label.
blacklistedbooleanTrue only when a reference list names this exact address with sufficient confidence. A real boolean, never a string. Necessary but not sufficient: an address can be unlisted and still score 100 on traced exposure.
blacklist_notestringHuman-readable basis for the flag.
risk_sources_countintegerNumber of distinct flagged sources this address is connected to.
risk_sources_notestringDescribes what the count refers to.
score_zones[]array{ label, range_min, range_max }. Published bands: Very Low 0–25, Low 26–40, Medium 41–50, High 51–75, Very High 76–100.
token_balances[] — current holdings
tokenstringSymbol, e.g. ETH, USDT.
contract_addressstringToken contract. Empty for the native coin.
balancenumberCurrent balance in token units.
wallet_statistics — activity
received_transactions_count
sent_transactions_count
total_transactions_countintegerTransfer events (native coin + ERC-20 / TRC-10 / TRC-20) where the address is sender or receiver, over all history. Not external transaction count and not internal calls.
first_transaction_utc
last_transaction_utcstringFirst and last activity, ISO-8601 UTC. Empty when the address has no history.
wallet_age_daysintegerDays since first activity.
statusstringACTIVE or INACTIVE. INACTIVE with zero transactions means a new or unused address — unexamined, not cleared.
stablecoin_inflow_usd
stablecoin_outflow_usd
stablecoin_turnover_usdnumberVolume in USD-pegged stablecoins specifically, readable as dollars without holding a price date in mind.
funded_by_entity_type_distribution[] — where the money came from
labelstringCounterparty name where known, otherwise a structural description such as Unnamed high-volume service.
percentagenumberShare of the denominator. Share of value, not of transfer count, unless denominator says otherwise.
category_codestringTaxonomy code — see the category dictionary. Threshold on this, not on label.
category_labelstringDisplay name for the code.
entity_classstringendpoint or service. Empty for unattributed funders.
risk_bearingbooleanTrue when this funder carries a risk attribution. False for merely unattributed funders.
sourcestringList or registry that produced the attribution. Empty when unattributed.
transfer_countintegerNumber of transfers behind this share.
denominatorstringtotal_priced_inflow_usd, or incoming_transfer_count when nothing received carries a price. Read this before comparing shares.
risk_factors.blacklists — direct listing summary
statusstringFlagged or Clear.
scoreintegerHighest severity among direct listings, or 0.
detailstringExplanation, including the contract case: a contract belonging to a recognised project is reported as such and not scored as a wallet.
risk_factors.reported_connected_addresses[] — flagged counterparties by severity band
severitystringBand: Severe / High / Medium / Low. Describes the connected source, not the address you queried.
scoreintegerHighest numeric severity in the band.
address_countintegerNumber of addresses in the band.
statusstringCurrently always Reported.
addresses[]array{ address, hops }. hops is the real graph distance with no smoothing; 0 means the queried address itself.
risk_factors.factors[] — one entry per finding the decomposition
kindstringWhich signal produced it: blacklist, indirect_exposure, direct_counterparty, counterparty_venue, entity_risk, geo_risk, trusted_entity, operator_flagged, contract.
category_codestringStable taxonomy code — see the dictionary.
category_labelstringDisplay name for the code.
entity_classstringendpoint — the source is itself the risk. service — a business holding third-party funds.
list_typestringAuthority behind the match: sanctions, law_enforcement, hack_attribution, issuer_freeze, community_report, operator_rating, derived. This is what separates a government designation from a user complaint.
sourcestringThe list or registry that matched. proportional_graph means the finding comes from traced value rather than a named list.
entitystringDesignated entity or company, where known.
jurisdictionstringIssuing authority for a sanctions match, where held.
severityinteger0–100 severity of the source. Never reduced by distance: a source six hops away carries its full severity.
directnessstringdirect — this address is named. indirect — inferred from the graph. The two are never merged.
hopsintegerReal distance. 0 = the address itself. -1 = a path exists but was not resolved because an intervening service breaks the chain of custody; the severity is still reported.
share_pctnumberShare of the denominator attributable to this finding.
amount_usdnumberAbsolute value attributable to this finding. Use alongside share_pct: a small share of a large balance is material, a small share of a small one is not.
denominatorstringWhat share_pct is a share of — total_priced_inflow_usd or incoming_transfer_count.
contribution_pointsnumberPoints this component contributed.
detailstringOne-sentence summary for a reviewer.
risk_factors.score_breakdown — what each component contributed
direct_listingnumberContribution from a listing naming this address.
counterpartynumberContribution from who funded it directly.
indirect_exposurenumberContribution from value traced through the graph.
concentrationnumberContribution from how concentrated that exposure is.
activity_baselinenumberBaseline from activity alone. An address nothing is known against is unexamined, not cleared, so this is never zero for an active address.
entity_penaltyintegerAdded for risk carried by the linked company or person.
geo_penaltyintegerAdded for jurisdiction risk.
recognised_entity_credit_appliedbooleanTrue when a recognised-operator credit reduced the score, so a major exchange is not scored as dirty for handling everyone's funds.
counterparty_is_rated_servicebooleanTrue when the worst direct funder is a rated business rather than a crime source. In that case the finding is about counterparty selection, not about the funds being criminal.
treated_as_servicebooleanTrue when the address itself behaves as a high-throughput service, whose inferred exposure describes its depositors more than itself.
service_basisstringWhy that determination was made, e.g. named service, high-throughput service, not a service.
scorenumberThe final score, repeated for convenience.
degraded_lookups[]arrayComponents that failed. Non-empty implies status: partial. A failed lookup lowers the score mechanically, so it must not be read as a cleaner address.
notestringComponents are not additive — the score is not their sum.
risk_factors.excluded_below_threshold — exposure found but not scored
tainted_usdnumberTraced value that fell below the materiality threshold.
source_countintegerHow many sources it came from.
notestringExcluded never means hidden. Immaterial exposure is reported here so a reviewer can see it and apply their own threshold.
entity_attribution — who the address belongs to
attributionstringresolved or none_held. Branch on this. A company or person is held for a small minority of addresses, so none_held is the normal answer — it means none was found, not that none exists, and never that the address is clean.
notestringPlain-language restatement of the above.
entity.kindstringcompany or person. Present only when attribution = resolved.
entity.id / entity.namestringIdentifier and display name of the organisation or individual.
entity.risk_scoreinteger0–100 risk held against the entity itself, independent of this address. 0 when the entity is known but carries no risk.
entity.jurisdictions[]arrayCountries linked to the entity.
entity.reasons[]array{ source, weight, detail } — why the entity carries risk.
address_label.labelstringLabel held for this specific address, e.g. a named exchange wallet.
address_label.companystringOperator this address is attributed to.

Category Dictionary

The distinction that matters. An endpoint is itself the risk, and exposure propagates from it. Recommended Integration Policy

Fail closed
1holdAny response other than 200, any body you cannot parse, and any status != "complete". A missing, null or zero score is never a pass.
2blockrisk_assessment.blacklisted = true, at any score.
3blockrisk_assessment.score >= 76, the start of the top band. Prefer a band boundary to an arbitrary round number.
4blockwallet.entity_tag = "Smart contract" on a plain transfer. Tokens sent to a token contract are unrecoverable — a loss case, not a risk case.
5reviewA funded_by_entity_type_distribution[] entry whose category_code you do not accept, above a share you choose. A rated venue will not on its own push a score into the top band, so threshold on the category if that matters to you.
6warncoverage = "no_history". Unexamined, not proven clean.
7noteUse score, never risk_level, in logic — there is no MEDIUM label, so 41–50 reads LOW RISK.

Reproducibility & Caching

Two identical calls return a byte-identical payload apart from report.generated_at_utc. report_id is a digest of the address, network, requested block, model_version and the data watermark, so it is safe as a cache key: if it has not changed, neither has the verdict. When it does change, something that affects the answer changed — new data, a new model version, or a different block.

Risk Grade API

Fast, API-key authenticated risk grade for any on-chain wallet address. Returns a single grade value indicating the address's risk tier.

Note: The time field in responses is a Unix timestamp (seconds) indicating when the risk grade was last computed for the given address.

Base URL

https://api.alpha-aml.com

GET /api/engine/risk-grade

Returns the current risk grade for a wallet address.

GET /api/engine/risk-grade?address={address}
