Risk Score API

Wallet and transaction risk lookups backed by the Alpha AML upstream API. Returns a styled PDF report for an address, or JSON risk metadata for the two parties of a transaction.

Base URL

https://api.alpha-aml.com

GET /api/report/wallet

Returns a PDF AML risk report for the given wallet address and chain.

GET /api/report/wallet?address={address}&chain={chain}

Headers

HeaderDescription
X-apikeyrequired Caller JWT. Per-key rate limits apply (10/s, 100/min, 2000/day). Not a query parameter — sending it as ?apiKey= no longer works.

Query Parameters

ParameterTypeDescription
addressrequired string Wallet address to check. Blank or missing → 400.
chainoptional string Blockchain the address belongs to. If omitted, upstream API attempts auto-detection. When supplied, an address whose family does not match the chain is rejected with UNSUPPORTED_CHAIN.

Supported chain values:

ETH ARB BASE BSC TRON

Response

StatusContent-TypeBody
200application/pdfGenerated PDF bytes. Header: Content-Disposition: attachment; filename="aml-report-<address>.pdf".
400application/jsonINVALID_ADDRESS (bad format), UNSUPPORTED_CHAIN (address family ≠ chain), BAD_REQUEST (missing param).
401application/jsonMissing or invalid X-apikey — rejected before this endpoint runs.
403application/jsonKey has no access to this endpoint.
404application/jsonADDRESS_NOT_FOUND — no upstream data for the address.
429application/jsonRate limit exceeded — Retry-After header and retry_after_seconds in the body say when to retry.
500application/jsonPDF_FAILED — Chromium failed to render the report.
App-level errors (400/404/500) are JSON — { "error": { "code", "field", "message" } }. Auth/rate-limit errors (401/403/429) come from the SDK layer before the request reaches this endpoint. Every response — success or error — carries an X-Request-Id header for tracing. A successful call still returns the raw PDF. See the Error Reference for app-level codes.

curl Examples

curl -H "X-apikey: <key>" \
  "https://api.alpha-aml.com/api/report/wallet?address=0x7f367cc41522ce07553e823bf3be79a889debe1b&chain=ETH" \
  -o aml-report.pdf
COPY 
curl -H "X-apikey: <key>" \
  "https://api.alpha-aml.com/api/report/wallet?address=TXyz1234567890abcdefgh&chain=TRON" \
  -o aml-report.pdf
COPY

GET /api/report/txhash

Resolves a transaction hash to a single transfer, then returns JSON risk metadata for both parties of that transfer. This endpoint does not generate a PDF — use /api/report/wallet with the returned sender / receiver for the styled report.

GET /api/report/txhash?txHash={txHash}&chain={chain}

Headers

HeaderDescription
X-apikeyrequired Caller JWT. Per-key rate limits apply (10/s, 100/min, 2000/day). Not a query parameter — sending it as ?apiKey= no longer works.

Query Parameters

ParameterTypeDescription
txHashrequiredstringTransaction hash. EVM chains: 0x + 64 hex. TRON: 64 hex, no 0x. Wrong shape for the chain → INVALID_TX_HASH.
chainrequiredstringChain to resolve the transaction on. One of the supported values below.
event_indexoptionalintegerFilter: keep only the token transfer whose log index equals this value (the number shown under a transaction's event logs on a block explorer). Native transfers have no log index.
token_contractoptionalstringFilter: keep only token transfers of this contract address.
senderoptionalstringFilter / assertion: keep only transfers sent from this address.
recipientoptionalstringFilter / assertion: keep only transfers received by this address.

Supported chain values:

ETH ARB BASE BSC TRON

Transfer Selection

Exactly one transfer is scored. The optional parameters filter the transaction's transfers — the native value transfer (if any) plus every ERC-20 / TRC-20 Transfer log event.

SituationResult
No filters — exactly one native transfer, no token transfersThat native transfer is used.
No filters — no native transfer, exactly one token transferThat token transfer is used.
No filters — a native transfer and token transfers, or more than one token transfer409 MULTIPLE_TRANSFERS — add a filter.
No filters — no transfers at all409 NO_TRANSFERS.
Filters given — no transfer matches409 NO_MATCH.
Filters given — more than one transfer still matches409 MULTIPLE_TRANSFERS — narrow further.
Filters given — exactly one matchThat transfer is used.

Response

StatusContent-TypeBody
200application/jsonTransfer metadata + risk scores (fields below).
400application/jsonINVALID_TX_HASH, UNSUPPORTED_CHAIN, INVALID_ADDRESS, BAD_REQUEST.
401application/jsonMissing or invalid X-apikey — rejected before this endpoint runs.
403application/jsonKey has no access to this endpoint.
404application/jsonUNKNOWN_HASH, ADDRESS_NOT_FOUND.
409application/jsonPENDING_TRANSACTION, TRANSACTION_FAILED, NO_TRANSFERS, MULTIPLE_TRANSFERS, NO_MATCH.
429application/jsonRate limit exceeded — Retry-After header and retry_after_seconds in the body say when to retry.
502application/jsonRPC_ERROR — RPC provider unreachable or returned an error.

Response Fields (200 OK JSON)

application/json — transfer metadata + risk scores
versionstringResponse schema version (e.g. "1.2.15"). Constant until this endpoint's response shape changes.
hashstringThe transaction hash (echo of txHash).
chainstringChain the lookup ran on (echo of chain).
amountstringTransferred amount, decimal-adjusted, trailing zeros stripped (e.g. "490.14").
amount_rawstringTransferred amount in base units (wei / sun / token base units).
assetstring"native" for a coin transfer, otherwise the token contract address.
decimalsnumberDecimals used for amount — 18 (native EVM), 6 (native TRON), or the token's own.
token_symbolstringToken symbol if it could be read on-chain; omitted for native transfers or when unavailable.
senderstringThe selected transfer's from address.
funding_entity_typesarraySender only. The sender's funded_by_entity_type_distribution from the Alpha AML API — [{ label, percentage }]. Omitted if the sender has no funding data.
receiverstringThe selected transfer's to address.
sender_risk_scorenumber0–100 risk score for sender. null if it could not be scored.
receiver_risk_scorenumber0–100 risk score for receiver. null if it could not be scored.

Error Reference

Both /api/report endpoints return app-level errors as JSON:

{ "error": { "code": "INVALID_ADDRESS", "field": "address", "message": "Not a valid address: zzz" } }

field is present only when the error concerns a specific parameter.

CodeHTTPTrigger
BAD_REQUEST400A required parameter is missing or blank, or has the wrong type.
INVALID_ADDRESS400address / sender / recipient / token_contract is not a valid EVM or TRON address.
UNSUPPORTED_CHAIN400chain is not supported, or an address's family does not match chain (e.g. a T… address with chain=ETH).
INVALID_TX_HASH400txHash is not a valid hash for the requested chain.
UNKNOWN_HASH404The RPC node does not know txHash.
ADDRESS_NOT_FOUND404The Alpha AML upstream has no data for the address.
PENDING_TRANSACTION409The transaction exists but is not yet mined.
TRANSACTION_FAILED409The transaction was mined but reverted.
NO_TRANSFERS409The transaction moved no native coin and emitted no token Transfer events.
MULTIPLE_TRANSFERS409More than one transfer is in scope — supply or narrow the filters.
NO_MATCH409No transfer matches the supplied filters.
PDF_FAILED500/report-v1 only — Chromium failed to render the PDF.
RPC_ERROR502The RPC provider or the upstream Alpha AML API was unreachable or returned an error.

Error Response Examples

// Ambiguous transaction

Risk Grade API

Fast, API-key authenticated risk grade for any on-chain wallet address. Returns a single grade value indicating the address's risk tier.

Note: The time field in responses is a Unix timestamp (seconds) indicating when the risk grade was last computed for the given address.

Base URL

https://api.alpha-aml.com

GET /api/engine/risk-grade

Returns the current risk grade for a wallet address.

GET /api/engine/risk-grade?address={address}

Headers

HeaderDescription
X-apikeyrequired API key for authentication. Missing or invalid → {"error":"Unauthorized"}. Not a query parameter — ?apiKey= no longer works.

Query Parameters

ParameterTypeDescription
addressrequired string Wallet address to grade. Must be a valid on-chain address. Missing → {"error":"Address is required"}.

curl Example

curl -H "X-apikey: <key>" \
  "https://api.alpha-aml.com/api/engine/risk-grade?address=0xd7632A8A3dC9287Ea25d2903df0cFb8702C49572"
COPY

Success Response (200)

{ address, riskGrade, status, time }
addressstringThe queried wallet address (echo).
riskGradestringRisk tier. One of: very-low, low, high, very-high.
statusstring"success" on a valid result.
timeintegerUnix timestamp (seconds) indicating when this risk grade was last computed for the address.
{
  "address": "0xd7632A8A3dC9287Ea25d2903df0cFb8702C49572",
  "riskGrade": "very-low",
  "status": "success",
  "time": 1751500800
}

Grade Values

The riskGrade field carries one of four tiers:

very-low
low
high
very-high
GradeInterpretation
very-lowAddress has very low risk exposure — minimal suspicious activity detected.
lowAddress has low risk — some indirect exposure but generally clean.
highAddress has high risk — notable exposure to flagged counterparties or patterns.
very-highAddress has very high risk — direct blacklist match or severe exposure.

Error Reference

All errors return a JSON body with an error field.

Error bodyTriggerHTTP Status
{"error":"Unauthorized"} Missing, invalid, or expired X-apikey header 401
{"error":"Address is required"} address parameter is missing or empty 400
{"error":"Unsupported address format"} address provided but not a valid on-chain address format 400
{"error":"Rate limit exceeded"} API key quota exhausted 429
